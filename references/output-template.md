# Output Template

Adapt the depth to the user's request. Use compact tables and name every evidence source.

## Executive snapshot

- Article URL and comparison periods.
- Change in clicks, impressions, CTR, and average position.
- Biggest visibility risk, fastest recoverable opportunity, and confidence level.
- Data gaps, especially whether cannibalization was checked.

## 1. Lost-impression recovery

| Priority | Query cluster | Representative query | Previous impressions | Current impressions | Loss | Position before → now | Diagnosis | Content action |
|---|---|---|---:|---:|---:|---:|---|---|

Lead with relevant lost impressions, not click loss. Separate irrelevant or questionable queries into an exclusion note.

## 2. Visibility protection list

| Protection level | Query cluster | Current impressions | Current clicks | Trend | Current position | What must remain |
|---|---|---:|---:|---:|---:|---|

Explicitly state which sections, tables, FAQs, examples, images, and entities must not be removed.

## 3. Similar-page relationship map

| Page | Role | Shared intent/queries | Risk | Recommended relationship |
|---|---|---|---|---|

State whether ownership is confirmed by query-page data or is only a hypothesis.

## 4. Safe refresh outline

Provide an ordered H1/H2/H3 outline. Mark each item:

- `[KEEP]` protects current visibility.
- `[STRENGTHEN]` recovers lost visibility.
- `[ADD]` fills a relevant missing intent.
- `[LINK]` routes to another owner page.
- `[REMOVE/CONSOLIDATE]` only when evidence supports it.

## 5. Writing notes

Include:

- The exact user question each section should answer.
- A concise direct-answer block where useful.
- Evidence, examples, tables, images, or FAQs needed.
- Claims requiring authoritative citations or expert review.
- Phrases to avoid because they are absolute, misleading, or stuffed.

## 6. Measurement plan

- Record the publication date and unchanged baseline.
- Request reindexing only if the user asks or handles it manually.
- Recheck GSC after 2 weeks for discovery/indexing signals and after 4–6 weeks for impressions, position, and query coverage.
- Compare the same page, search type, country/device filters, and equivalent periods.
- Track Recover and Protect clusters separately.
